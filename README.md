
Motor de Banco de Dados Híbrido (C & Python)
- Situação: O projeto surgiu da necessidade de entender como os bancos de dados gerenciam o armazenamento de baixo nível enquanto mantêm uma interface acessível para o usuário final.
- Tarefa: O desafio foi desenvolver um motor de busca e armazenamento que fosse performático, utilizando Linguagem C para o processamento, e uma camada de interatividade em Python para facilitar a manipulação dos dados.
- Ação: Desenvolvi o núcleo (engine) em C, focando em lógica de ponteiros e manipulação de arquivos para persistência de dados. Integrei este motor a um script Python que atua como interface de linha de comando (CLI), permitindo que o usuário realize operações de inserção e consulta de forma intuitiva.
- Resultado: O projeto resultou em um sistema funcional que demonstra competência técnica em integração de linguagens distintas e resolve o problema de abstração de complexidade, servindo como uma prova prática de domínio em Lógica de Programação e arquitetura de software.
